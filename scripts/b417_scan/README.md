# b4.17 有限温度与体积扫描项目 (b417_scan)

> **定位说明**：本目录 (`scripts/b417_scan/`) 专门归集**固定规范耦合 $\beta=4.17$** 条件下的有限温度（不同 $N_t$）与有限体积（不同 $N_s$）介子扫描分析。
> 与 LCP 项目（固定时空尺寸 $48^3\times 16$ 改变 $\beta$ 调谐温度）不同，**b417_scan 项目是在固定晶格间距 $a(\beta=4.17)$ 下，通过改变时间方向点数 $N_t \in \{12, 14, 16, 18\}$ 改变温度，并改变空间尺度 $N_s \in \{32, 36, 40, 48\}$ 检验体积标度行为。**

---

## 1. 项目覆盖的 24 组格点系综

固定奇异夸克质量 $m_s = 0.040$，涵盖 4 组轻夸克质量 $m_l \in \{0.0020, 0.0035, 0.0070, 0.0120\}$：

| 序号 | 规模标签 | 时空点数 | 夸克质量 $m_l$ 集合 | 参考温度 $T$ (MeV) | 物理目的 |
|:---:|:---|:---|:---|:---:|:---|
| 00 | `32x12` | $32^3 \times 12$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 204.00 | 高温区 ($T > T_c$) |
| 01 | `32x14` | $32^3 \times 14$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 174.86 | 稍高于相变温度 |
| 02 | `32x16` | $32^3 \times 16$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 153.00 | 相变过渡带 ($N_s=32$ 小体积) |
| 03 | `36x18` | $36^3 \times 18$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 136.00 | 低温区 ($N_s=36$) |
| 04 | `40x16` | $40^3 \times 16$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 153.00 | 相变过渡带 ($N_s=40$ 中体积) |
| 05 | `48x18` | $48^3 \times 18$ | 0.0020 / 0.0035 / 0.0070 / 0.0120 | 136.00 | 低温区 ($N_s=48$ 大体积) |

## 2. 脚本清单与职责分工

| 脚本文件 | 基础功能 | 对应产物路径 |
|---|---|---|
| `reproduce_meson_b417_nt_scan.py` | 核心扫描计算脚本：24 系综 $\times$ 6 信道空间关联函数抽取、以 $N_s/2$ 为中心求解有效质量、自动检测平台拟合介子质量 | `output/meson_scan/b4.17/multisrc/`, `output/meson_scan/b4.17/singlesrc/` |
| `run_meson_b417_scan.py` | 顶层包装入口：支持多进程并发控制与自动出图调度 | 同上 |
| `run_meson_b417_nt_scan.sh` | Bash 批处理执行入口 | 同上 |
| `measure_meson_b417.py` | 介子质量测量与温度演化图渲染 | `docs/meson_mass_T_*.png` |
| `plot_effective_mass_b417.py` | 有效质量曲线与拟合窗口可视化诊断 | `docs/effective_mass/` |
| `try_fit_window.py` | 针对特定系综的平台拟合窗口试算与 $\chi^2/\text{dof}$ 诊断 | 控制台诊断打印 |
| `plot_split_raw.py` | 拆分“48^3x16 全温度扫描”与“固定 beta=4.17 序列”原始数据图 | `output/condensate/split/` |

---

## 3. 运行示例

```bash
# 1. 快速检查 24 个系综目录清单 (Dry Run)
uv run python scripts/b417_scan/reproduce_meson_b417_nt_scan.py --dry-run

# 2. 运行指定格点与夸克质量
uv run python scripts/b417_scan/reproduce_meson_b417_nt_scan.py --cases 48x18 --ml 0.0020 --force

# 3. 全量运行 (多源 + 单源，4 进程并发)
bash scripts/b417_scan/run_meson_b417_nt_scan.sh
```
